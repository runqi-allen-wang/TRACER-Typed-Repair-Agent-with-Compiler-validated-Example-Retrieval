# LeanCapsule challenge sources

This directory is an evaluation-only challenge set, separate from the public
core gallery in `capsules/`.  Challenge limitations such as full-file fallback,
diagnostic drift, or replay failure are measured outcomes and do not fail the
core gallery release audit.

Each case contains a compiling `Correct.lean`, a single-point mutation in
`Error.lean`, machine-readable `metadata.json`, and a short design note.
