## Protocol

Each case contains a compiling `Correct.lean` and a one-line-mutated failing `Error.lean`. The runner compiles both, packs the failing theorem, copies the capsule to a fresh temporary directory, rebuilds project-local Lean sources when required, and compares compile status, category, diagnostic key, and the complete ordered normalized diagnostic text.

The 12 core cases are a hard gate. Challenge outcomes are always retained rather than filtered. This finite synthetic experiment demonstrates the implemented matrix only; it is not evidence for arbitrary Lake projects.
